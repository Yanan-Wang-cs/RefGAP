The problem

Editors see the reference — but hardly attend to it

In-context editors put reference tokens in the same attention sequence as the content being edited. Yet when we measure the share of attention that edit-region queries give to the reference, it is often far below what even uniform attention would give.

<1%

of edit-region attention mass goes to the reference in LoomVideo.

Edit-region reference attention vs. uniform

Method

Measure, then correct — two-sided and online

At every selected layer and denoising step, RefGAP reads the reference-attention mass for the edit region (E) and the keep region (K), and adds a single scalar to the reference-key logits of each query.

1

Measure

Average each query's attention on reference keys, separately over edit and keep regions.

ρ̄edit, ρ̄keep
2

Set the bias

Low reference attention in the edit → larger boost. Keep region gets a suppressing offset so the change stays local.

bedit = +γedit·log(1/ρ̄edit)
bkeep = −γkeep·log(1/ρ̄keep)
3

Correct the logits

Shift reference logits only; relative weights inside each key group are preserved. A fixed rule picks all layers or the second half.

sij ← sij + bg,  j ∈ R

Shared everywhere: γedit=0.6, γkeep=0.8, τB=2.7, τb=3.7. A new editor only needs one profiling run to pick its layer set.
